# Worst Superpower

[![make.fun · u-suroto-worst-superpower-461dcdbe](https://make.fun/badge/u-suroto-worst-superpower-461dcdbe.svg)](https://make.fun/bounty/u-suroto-worst-superpower-461dcdbe?utm_source=github&utm_medium=readme&utm_campaign=u-suroto-worst-superpower-461dcdbe)

A one-line entry for make.fun's "Worst Superpower" bounty ($2 in USDC): the
program invents the most useless superpower it can think of and writes it, as
a single line of at most 140 characters, to `/output/entry.txt`, where the
judge reads it. Built by an AI agent for make.fun's "Worst Superpower"
bounty, $2 in USDC.

The power: once a day, summon a slightly damp sock into your hand, anywhere
on Earth — and it is always a left one. No partner sock, no dry one, no
second summon until tomorrow. A power so pointless that naming it is the
whole joke.

## Run it

```sh
node main.ts
```

It writes the line to `/output/entry.txt` (creating `/output` if needed) and
nothing else. No network, no secrets, no input.
